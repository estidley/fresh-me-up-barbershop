## Platform

## Product Purpose

Simple independent marketing demo for Fresh Me Up Barbershop in Plano. Help visitors choose a service and book on the shop's existing Booksy page. Not the shop's official site unless adopted.

## Users

Assumed audience: local customers considering haircuts, fades, beard work, or children's cuts.

## Capabilities and Constraints

Preserve booking, phone, directions, address, and useful service information. Existing Vite static site on Railway. Keep scope small. Restore editable HTML and CSS from the existing generated-only build.

## Brand Commitments

User requests a complete redesign with its own layout, distinct from Pasha. Black, white, gray, and hexagons reflect the shop. No colored accents. Natural, concise copy using Humanizer. User chose visual mockups for approval before coding.
